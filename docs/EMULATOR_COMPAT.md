# Compatibilité de l'émulateur

Résultats des essais de jeux dans la page `/games/:id/play`. Le statut de chaque jeu (**Testé**, **Non testé**, **Ne marche pas**) se règle sur sa fiche et s'affiche en badge sur la fiche et dans la bibliothèque.

## Comment tester un jeu

1. Ouvrir la fiche du jeu, puis « Jouer ».
2. Noter : le jeu **démarre-t-il** (logo, menu) ; la **vitesse** avec le moteur `cached` (pleine vitesse, ralenti, injouable) ; le **son** (présent, craquements, absent) ; la **manette** (toutes les touches utiles répondent) ; la **mémoire** : après avoir quitté la page, l'onglet ne garde pas de mémoire en plus (outils du navigateur, onglet Mémoire).
3. Tester aussi la sauvegarde : touche `K`, quitter, rouvrir, la partie doit reprendre.
4. Régler le statut sur la fiche du jeu et remplir une ligne ci-dessous.
